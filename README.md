# DSS2 — Todo Management API

Backend REST API + Frontend React pour le projet DSS2.

## Stack
- **Backend**: Node.js 20 + Express
- **DB**: PostgreSQL 16
- **Auth**: JWT
- **Docs**: Swagger UI à `/api/docs`
- **Bonus**: Redis (cache) + RabbitMQ (events)
- **Frontend**: React 18 + Material UI

## Démarrage rapide (Docker)

```bash
docker compose up --build
```

- API: http://localhost:3087
- Swagger: http://localhost:3087/api/docs
- Frontend: http://localhost:5173
- RabbitMQ UI: http://localhost:15672 (guest/guest)
